Authority: [DESIGN.md](../DESIGN.md), updated 2026-11-16.

Paper dictionary, ink text, terracotta bookmarks, Fraunces headwords and small existing illustrations. Operate mode: start learning, understand a word, manage a personal wordbook.

4px spacing base; 12/14/16/20/24/36–48px type in rem; 52px primary / 44px secondary and icon targets; 12px buttons / 16px panels. Use existing semantic paper/ink/terra/sage tokens in both themes. One primary action per task group. Optional article and plural are part of WordIdentity; no fake placeholders. Mobile detail returns to the shelf instead of placing a shelf before the word list. Storage and review logic remain in their existing owners.
